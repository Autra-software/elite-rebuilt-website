# Office photos

Drop real photos here with these exact file names. Each one replaces its
placeholder on the page automatically (restart `npm run dev` if it doesn't show).

| File | Shows | Shape |
|---|---|---|
| `office-front.jpg` | Front of the office | Large, landscape |
| `inspection-area.jpg` | Where vehicles are inspected | Landscape (4:3) |
| `inspector.jpg` | Inspector checking a vehicle | Landscape (4:3) |
| `waiting-area.jpg` | Customer waiting area | Wide landscape |

Tips: JPG, at least 1600 px wide, under 1 MB. Real photos of the office only;
no stock photos. In production, sections without photos are hidden.
